## Selected work

**[CAPRI: federated unlearning for intrusion detection](https://github.com/ibrahimghauri009/capri-federated-unlearning-ids)**
Measures how much attack-family detection a federated intrusion detection system loses when the only
client holding that family leaves, predicts the loss before deletion, and repairs it from a small
exemplar set. 115 logged federated runs on two IoT datasets; every number in the paper is regenerated
from the logs. PyTorch · statsmodels · LaTeX ·
[paper PDF](https://github.com/ibrahimghauri009/capri-federated-unlearning-ids/blob/main/paper/main.pdf)

**[Contract Risk Analyzer](https://github.com/ibrahimghauri009/contract-risk-analyzer)**
Clause retrieval over commercial contracts (dense + BM25 + cross-encoder reranking) and clause-type
classification on CUAD, with a FastAPI service and Streamlit UI.
sentence-transformers · scikit-learn · FastAPI · Streamlit

**[Business Registry Consensus API](https://github.com/ibrahimghauri009/business-registry-consensus-api)**
Looks up company registrations across three public registers (Companies House, GLEIF, OpenCorporates),
reconciles them by weighted consensus and stores results in PostgreSQL with TTL-based lifecycle.
FastAPI · PostgreSQL · Docker · 127 pytest tests

**[Retail data warehouse with MESHJOIN](https://github.com/ibrahimghauri009/retail-data-warehouse-meshjoin)**
Near-real-time ETL that joins a live sales stream with master data (MESHJOIN, with load shedding) and
loads a MySQL star schema; 20 OLAP queries on top. Python threads · MySQL
